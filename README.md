# CareConnect - Healthcare Portal Prototype

CareConnect is a responsive healthcare web platform built to help users quickly find nearby hospitals, check real-time availability of ICU beds and blood stock, and access emergency contacts.

## Key Features
- **Hospital Search & Filtering:** Filter by area, hospital name, and blood group requirements.
- **Theme Toggle:** Instant switching between Dark Mode and Light Mode.
- **Emergency Modal Desk:** Direct pop-up displaying key contact details for quick emergency assistance.

## Tech Stack
- HTML5
- CSS3
- JavaScript
